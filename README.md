# Business Intelligence

Coursework from the **Business Intelligence** course taken during my Erasmus exchange at IPCB (Instituto Politécnico de Castelo Branco, Portugal), Master's Degree in Computer Engineering.

## Project 1 — Neo4j

[`project1/`](project1) — analysis of the StackOverflow community dataset using Neo4j AuraDB: graph modeling, data import via Cypher, database/dashboard exploration, and an AI agent built on top of the graph. My own work, solo.

- [`BI_project.pdf`](project1/BI_project.pdf) — the full report.
- [`stackoverflow-data-importer/`](project1/stackoverflow-data-importer) — the dataset (from the [official Neo4j Graph Examples repo](https://github.com/neo4j-graph-examples/stackoverflow)) and import model used to build the graph.
- [`Projeto 1 - Neo4j.pdf`](project1/Projeto%201%20-%20Neo4j.pdf) — the assignment brief.

## Project 2 — Databricks

[`project2/`](project2) — ingestion, transformation and analysis of a different dataset on Azure Databricks (Delta Lake tables, AI/BI dashboards, a simple ML model), to compare a graph database against a data-lakehouse architecture. Group work (4 students, myself included) — the report reflects the whole group's effort, not a solo submission.

- [`BI-Trabalho2.docx`](project2/BI-Trabalho2.docx) — the group's report.
- [`Projeto 2 - Databricks-2.pdf`](project2/Projeto%202%20-%20Databricks-2.pdf) — the assignment brief.
